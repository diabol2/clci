# SLCI — Индекс стохастической логистической связанности

Проект выполнен в рамках кейса **А2 «Индекс транспортной связанности»** (партнёр — **РВБ / Wildberries & Russ**). 

Инструмент оценивает, насколько надёжно сеть доставки последней мили (СЦ → ПВЗ) укладывается в целевое окно SLA, и позволяет сравнивать муниципальные округа и инфраструктурные сценарии улучшения сообщения с учётом численности населения и действующей сети ПВЗ.

---

## 1. Объект исследования и решаемая проблема

В Северо-Восточном секторе Нижегородской области (**Борский, Городецкий, Семёновский и Шахунский округа**, суммарно **284 000 жителей** и **110 ПВЗ**) доставка с действующих правобережных сортировочных центров РВБ в Нижнем Новгороде (**СЦ «Кудьма»** и **СЦ «Ларина»**) идёт через единственный **Борский мостовой переход** и трассу **Р-159**.

Из-за заторов на переправе, промежуточных перегрузок и редких рейсов удалённый Шахунский округ регулярно не укладывается в целевое окно `12 часов`. Проект позволяет количественно оценить уязвимость маршрутов и выбрать приоритетное решение (рост частоты рейсов, прямой рейс или открытие северного кросс-дока).

---

## 2. Математическая модель

Для каждого округа рассчитывается индекс `SLCI` (от `0` до `1`):

```text
SLCI = P(T ≤ T_SLA) · exp(−α·k − β·f_req/f_act) · (1 − γ·B)
```

| Обозначение | Смысл |
| :--- | :--- |
| `T ~ LogNormal(μ, σ)` | Время доставки (параметры `μ` и `σ` восстанавливаются из `E[T]` и `σ_T`) |
| `P(T ≤ T_SLA) = Φ((ln T_SLA − μ)/σ)` | Вероятность уложиться в целевое окно (по умолчанию `12 ч`) |
| `k` | Число промежуточных перегрузок (сортировок) на пути |
| `f_act / f_req` | Фактическая / нормативная (`2` рейса/сут) частота рейсов |
| `B ∈ [0, 1]` | Доля безальтернативных рёбер (мостов графа) на маршруте |
| `α=0.15, β=0.20, γ=0.35` | Весовые коэффициенты штрафов (см. анализ чувствительности) |

### Шкала оценки связанности
* **≥ 0.75** — высокая связанность (зелёная зона)
* **0.50 – 0.74** — умеренная связанность (жёлтая зона)
* **< 0.50** — критическая связанность (красная зона)

### Региональный бизнес-эффект
Поверх индивидуальных оценок округов вычисляется интегральный `SLCI` всего сектора, взвешенный по численности населения (данные Росстата) и количеству действующих ПВЗ (`sector_impact`).

## 3. Основные результаты расчётов (`SLA = 12 ч`)

### Базовое состояние округов

| Округ | Население, чел. | ПВЗ, шт. | `P(T ≤ SLA)` | **SLCI** | Зона |
| :--- | :---: | :---: | :---: | :---: | :--- |
| **Городецкий** | 83 000 | 32 | 1.000 | **0.72** | умеренная |
| **Борский** | 120 000 | 50 | 0.997 | **0.67** | умеренная |
| **Семёновский** | 45 000 | 16 | 0.985 | **0.60** | умеренная |
| **Шахунский** | 36 000 | 12 | 0.726 | **0.30** | критическая |

### Сценарии улучшения для Шахунского округа

| Вариант | Изменённые параметры | **SLCI** | Прирост | Зона |
| :--- | :--- | :---: | :---: | :--- |
| **Базовый** | `E[T]=10.4 ч, σ_T=3.5 ч, k=2, f_act=1, B=0.50` | **0.30** | — | критическая |
| **С1: 2 рейса в сутки** | `E[T]=9.2 ч, σ_T=3.0 ч, f_act=2` | **0.42** | +0.12 | критическая |
| **С2: прямой рейс** | `E[T]=7.8 ч, σ_T=2.2 ч, k=1` | **0.45** | +0.15 | критическая |
| **С3: Северный кросс-док** | `E[T]=6.8 ч, σ_T=1.6 ч, k=1, f_act=3, B=0.25` | **0.68** | +0.38 | умеренная |

* **Эффект для Семёновского округа в С3:** индекс вырастает с **0.60** до **0.80** (`+0.20`, переход в высокую зону).
* **Эффект для всего сектора:** взвешенный по населению SLCI растёт с **0.626** до **0.707** (по ПВЗ — с **0.633** до **0.705**). Из критической зоны выводятся все **36 000 жителей** и **12 ПВЗ** Шахуньи, а качество доставки улучшается суммарно для **81 000 человек** и **28 ПВЗ**.

## 4. Запуск и тестирование

```bash
# 1. Установка зависимостей
pip install -r requirements.txt

# 2. Запуск юнит-тестов (проверка монотонности, граничных условий и валидации)
python -m pytest

# 3. Полный расчёт: вывод таблиц в консоль + сохранение CSV и графиков в outputs/
python run.py
```

## 6. Честно о данных

* **Реальные открытые данные:** численность населения округов взята из статистики Росстата (`284 тыс. чел.`), количество действующих ПВЗ Wildberries собрано по открытым картам 2ГИС и Яндекс Карты (`110 точек`).
* **Синтетические допущения:** параметры маршрутов `E[T]`, `σ_T`, `k`, `f_act`, `B` в файле `slci/data.py` заданы экспертно на основе геометрии трассы Р-159 и зависимости от Борского моста. Следующий шаг развития проекта — заменить их фактической телематикой рейсов от СЦ «Кудьма» и «Ларина» и автоматическим расчётом доли мостов `B` по графу дорог алгоритмом Тарьяна.
