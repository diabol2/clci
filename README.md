# SLCI — Индекс стохастической логистической связанности

Кейс А2 «Индекс транспортной связанности». Инструмент оценивает, насколько надёжно
сеть доставки последней мили (хаб → ПВЗ) укладывается в целевое окно SLA, и позволяет
сравнивать территории и варианты улучшения сообщения.

## Формула
```
SLCI = P(T ≤ T_SLA) · exp(−α·k − β·f_req/f_act) · (1 − γ·B)
```
| Обозначение | Смысл |
|---|---|
| T ~ LogNormal(μ, σ) | время доставки (параметры из E[T] и σ_T) |
| P(T ≤ T_SLA) = Φ((ln T_SLA − μ)/σ) | вероятность уложиться в окно (по умолч. 12 ч) |
| k | число промежуточных перегрузок |
| f_act / f_req | фактическая / нормативная (2) частота рейсов в сутки |
| B ∈ [0,1] | доля безальтернативных рёбер (мостов графа) на пути |
| α=0.15, β=0.20, γ=0.35 | веса (экспертные, см. анализ чувствительности) |

Шкала: ≥0.75 высокая · 0.50–0.74 умеренная · <0.50 критическая.

## Запуск
```bash
pip install -r requirements.txt
python run.py          # таблицы + CSV и графики в outputs/
python -m pytest       # тесты
```

## Структура
```
slci/model.py     # DistrictNode, SLCICalculator (ядро)
slci/data.py      # входные данные и сценарии
slci/analysis.py  # Монте-Карло, чувствительность, устойчивость к SLA
slci/plots.py     # графики (matplotlib)
run.py            # точка входа
tests/            # тесты свойств модели
outputs/          # результаты расчёта
docs/TEAM.md      # распределение задач в команде
```

## Честно о данных
Параметры E[T], σ_T, k, f_act, B в `data.py` — **экспертные/синтетические допущения**,
а не измерения. Следующий шаг — заменить их данными OSRM/OSM (время в пути),
телематики и алгоритма Тарьяна по графу дорог (B).
